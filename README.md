# XizmatGo — умный сайт для заказа услуг

Учебный проект по дисциплине «Введение в программную инженерию» (ТУИТ).
Вариант № 8 «Разработка умного сайта для заказа услуг».
Автор: Камбарова Хатича, группа М320-24 ДИР. Преподаватель: Латипова Нодира.

## О проекте
XizmatGo — веб-платформа (SPA/PWA) для заказа бытовых услуг в Ташкенте: клиент находит
услугу, оформляет заказ с адресом и предварительной ценой, система подбирает мастера,
клиент отслеживает и оплачивает заказ (Payme / Click / Uzum) и оставляет отзыв.

## Возможности (подсистема SS-3 «Управление заказами»)
- расчёт предварительной стоимости (FR-04)
- принятие заказа мастером с проверками (FR-08)
- машина состояний заказа (FR-07)
- умный подбор мастера, паттерн «Стратегия» (FR-05)
- проверка фото заказа: до 5 шт., до 5 МБ, только JPG/PNG (FR-03, SR-08)
- повтор завершённого заказа одной кнопкой (US-15)
